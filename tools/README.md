# tools

Internal test tools. Not part of the shipped product.

Planned:

- `mock-host/`: stands in for the editor, serves sample H.264 video over the protocol (M1).
- `mock-client/`: stands in for the Android app, for testing the host without a phone (M1).
- `latency-scene/`: Godot scene that changes color on touch, for touch-to-display and 240 fps camera checks (M3).
